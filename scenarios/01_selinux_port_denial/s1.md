# Scenario 1 — SELinux Port Denial

The MCP server needs to:

1. Identify that the service failed to bind to the port.
2. Check the audit logs (`/var/log/audit/audit.log`) or use `journalctl` to find an SELinux AVC
   denial.
3. Use the `semanage` tool to allow HTTPD to listen on port 8088.

```bash
semanage port -a -t http_port_t -p tcp 8088
systemctl restart httpd
```
